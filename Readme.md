# WiFi Analyzer Clone Dashboard

Công cụ giám sát tín hiệu sóng Wi-Fi và phân tích độ nghẽn kênh Access Point.

## Tính năng
- Quét thời gian thực các trạm phát Wi-Fi (AP) xung quanh (SSID, BSSID, RSSI dBm, Chuẩn 802.11, Bảo mật).
- Biểu đồ phân bổ tín hiệu theo Kênh (Channel Graph).
- Đánh giá mật độ kênh và khuyến nghị kênh tối ưu 2.4 GHz (Channel Rating).

pip install flask
